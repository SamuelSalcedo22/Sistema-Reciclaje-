# Persistencia Local

Esta carpeta está reservada para los archivos generados por el almacenamiento local, como:
- `database.json` o `data.json` si se usa JSONStorage.
- `database.sqlite` o `db.sqlite3` si se usa SQLiteStorage.

**Aviso**: Los archivos de bases de datos locales (`*.json`, `*.sqlite`, `*.db`) deben ignorarse en el control de versiones `.gitignore` para no subir datos sensibles o de prueba al repositorio.
